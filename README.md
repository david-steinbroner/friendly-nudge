# Friendly Nudge

A little help keeping in touch.

Friendly Nudge is an iPhone app for remembering the people you want to make time for. It brings gentle reminders and a small daily check-in into a private space, without a social feed.

The project is designed around keeping personal information on your device. There are no user accounts or cloud sync.

## Explore the project

This repository contains the app source. Open `FriendlyNudge/FriendlyNudge.xcodeproj` in Xcode to work with it locally. Running it on your own iPhone requires Apple development signing.

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup and development guidance, and [the project handoff](docs/HANDOFF.md) for development notes.
